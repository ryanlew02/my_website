About

DivergeOS is built entirely from scratch — no UI libraries, no component kits. Every window, taskbar, drag handle, and notification is hand-crafted in React and TypeScript. It ships as a PWA and runs fully offline. Default passcode: insurgent.

Features
Window Manager
  • Drag and resize in 8 directions
  • Minimize, maximize, and close
  • Z-index stacking — focused window always on top
  • Taskbar with running window list and clock
  • Multi-select with marquee drag
  • Right-click desktop context menu
Applications
  • Notepad — text editor + virtual file system
  • Files — folder explorer with create, rename, delete
  • Chess — full rules, minimax AI, 3 difficulty levels
  • Terminal — CLI with custom command set
  • Calculator, Browser, Dictionary, Manifesto
  • Aptitude Test, Fear Simulation, Zip Line
Architecture
  • Zustand stores for windows, theme, FS, notifications
  • CSS custom properties for real-time faction theming
  • LocalStorage persistence for all user data
  • PWA service worker with offline asset caching
  • Lazy-loaded app modules for fast startup
  • Full TypeScript coverage across the codebase
